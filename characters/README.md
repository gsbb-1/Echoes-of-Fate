## Resolved decisions (2026-09-14)

- **Liam is Olivia's son.** Confirmed — see `liam.md` and `olivia.md`.
- **The connective mechanism** is a cold case: Michael's older brother,
  Daniel, disappeared from Willow Creek eighteen years ago and was never
  found — the unsolved case that still haunts Jack. Emma's late father was
  involved in a land deal around the same time and buried evidence to
  protect the family business; that buried evidence is Emma's secret.
  Olivia, a teenager in town at the time, was one of the last people to see
  Daniel and has never told anyone what she saw. Sarah has been painting a
  recurring, unexplained image of a place she's never consciously
  visited — it turns out to be tied to where Daniel was last seen. Liam's
  digging (curiosity, not knowing the history) is what eventually surfaces
  the connection publicly. Full detail in each character file and in
  `scenes/willow-creek.md`.
- **Timeframe:** roughly six weeks in early autumn, culminating at Willow
  Creek's annual Harvest Festival — the physical event where all six
  threads converge for the climax.

## The full mystery (resolved 2026-09-14)

The four plot mechanics the 2026-09-14 character-development pass left
open (Jack's present-day case, what Olivia actually saw, Sarah's
lake/orchard fragment, Daniel's rumored land-dispute interest) have all
been resolved by plot-research and folded into each character file. Ground
truth: Daniel died accidentally, confronting foreman Hank Colby over an
unfiled safety report at an unstable pond embankment — not murder — and
Warren Hale covered it up to protect the company. Full beat-by-beat design,
including the reveal order across the story and the fair-play red
herring/foreshadowing plants, is in `scenes/plot-map.md`. That file is now
the ground truth for the mystery; if a character file and `plot-map.md`
ever disagree going forward, `plot-map.md` wins and the character file
should be corrected.

No open questions currently block chapter drafting. New ones raised during
drafting should be logged here.
