# Scenes

Background and scene material that supports the manuscript but isn't prose
itself: setting/location notes and per-scene planning (who's in it, what
they want, what changes by the end).

- [willow-creek.md](willow-creek.md) — the town: what's established,
  what's still undefined
- `chapter-01/` etc. — as chapters get planned scene-by-scene, add a
  `chapter-NN/` folder here with one file per scene (goal, conflict, POV
  character, outcome) before drafting the prose in
  `manuscript/chapters/`

Nothing here is canon prose — it's working notes. When a scene is actually
written, the finished prose goes in `manuscript/chapters/`, not here.
