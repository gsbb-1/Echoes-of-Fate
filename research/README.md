# Research

Notes on writing styles and techniques to draw on while drafting — not part
of the story itself. Use this folder to collect things like: authors/books
whose voice or structure is worth studying, techniques for a specific craft
problem this manuscript has (see below), POV/tense conventions, pacing
references for multi-POV ensemble novels.

## Craft problems identified in this manuscript so far

- **Tell, don't show:** Chapter 1 (`manuscript/chapters/chapter-01.md`)
  states each character's inner conflict directly ("she felt confined by
  the expectations of her family") rather than dramatizing it through
  action, dialogue, or detail. Worth researching show-vs-tell technique
  before rewriting.
- **Uniform voice across POV characters:** all six characters are narrated
  in the same distant, descriptive register, so nothing distinguishes
  Sarah's chapters from Jack's. Worth researching how other multi-POV
  ensemble novels differentiate voice per character (sentence rhythm,
  vocabulary, what each character notices).
- **Stock description:** phrases like "deep blue eyes", "dark eyes",
  "carefully constructed facade" recur as generic shorthand rather than
  specific, character-revealing detail.

Add findings/notes here as separate files (e.g. `show-dont-tell.md`,
`multi-pov-structure.md`) as research is done, rather than growing this
README indefinitely.
