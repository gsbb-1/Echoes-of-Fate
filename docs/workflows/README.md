# Workflows

Design reference for the recurring pieces of work on this project ("core
functions"). Each file below documents one workflow: what it takes as
input, what it produces, and where those files live. These are living
design docs — update them when the actual process changes, rather than
letting them drift from how the project really works.

- [outline-design.md](outline-design.md) — planning/expanding the
  chapter-by-chapter structure
- [character-development.md](character-development.md) — building and
  deepening character profiles
- [plot-design.md](plot-design.md) — designing the mystery/plot layer that
  underlies the outline
- [scene-planning.md](scene-planning.md) — breaking a chapter down into
  scenes before drafting prose
- [chapter-drafting.md](chapter-drafting.md) — turning a scene plan into
  finished chapter prose
- [continuity-testing.md](continuity-testing.md) — automated checks that
  keep the manuscript internally consistent
- [publishing.md](publishing.md) — syncing finished chapters to the
  GitHub Pages site in `docs/`

See `AGENTS.md` for how these workflows fit into the project's overall
design → implement → test → commit loop, and `PLAN.md` / `TODO.md` for
what's actually in progress right now.
